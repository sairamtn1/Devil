## Installation

### Docker
```bash
docker pull volga/volga:latest
docker-compose up
```

### From Source
```bash
npm install
npm run build
npm start
```

---

## Upgrading

### From v0.x to v1.0
1. Backup your data
2. Stop the current instance
3. Pull the latest version
4. Run database migrations
5. Start the new version
