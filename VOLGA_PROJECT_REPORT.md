## Technology Stack

- **Runtime**: Node.js / TypeScript
- **API Framework**: Express.js
- **API Specification**: OpenAPI 3.1
- **Architecture**: Microservices (unified)

## Key Features

1. **Unified Intelligence Layer**: Single interface for all AI capabilities
2. **Mission Center**: End-to-end mission management
3. **Agent Network**: 10 specialized agents
4. **System Health Center**: Real-time monitoring
5. **Enterprise Ready**: Multi-tenant, RBAC, Audit
