## How to Get Started

### 1. Sign Up
Visit [volga.ai](https://volga.ai) and create an account.

### 2. Join Beta
Use beta code `BETA2024` or join the waitlist.

### 3. Create Your First Mission
```
POST /api/os/mission
{
  "title": "Build Portfolio",
  "description": "Create a modern portfolio website",
  "agents": ["coding", "deployment"]
}
```

### 4. Deploy
```bash
git clone https://github.com/sairamtn1/Devil.git
cd Devil
docker-compose up
```
